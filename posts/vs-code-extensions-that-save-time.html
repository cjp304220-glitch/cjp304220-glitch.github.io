VS Code is great out of the box, but a few extensions remove a lot of daily friction. These are the ones I'd install on a fresh machine.

Advertisement

1. Prettier

Formats your code on save so you never argue about spacing again. Turn on "editor.formatOnSave": true.

2. ESLint

Catches JavaScript/TypeScript bugs while you type.

3. GitLens

Shows who changed each line and why, right inside the editor.

4. Error Lens

Puts errors and warnings inline on the line itself, so you don't have to hover.

5. Live Server

Launches a local server with auto-reload for HTML/CSS work.

6. Thunder Client / REST Client

Test APIs without leaving VS Code.

7. Path Intellisense

Autocompletes file paths in imports.

Advertisement

8. Docker

Manage containers and images, and get Dockerfile hints.

9. Code Spell Checker

Catches typos in variable names and comments.

10. Remote - SSH

Edit code on a server or Raspberry Pi as if it were local.

Bonus tip

Use Settings Sync (sign in with GitHub) so your extensions and settings follow you to every machine.
