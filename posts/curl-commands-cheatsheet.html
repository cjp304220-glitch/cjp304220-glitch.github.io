curl Commands Every Developer Should Know (Cheatsheet)

curl ships with every Linux and macOS machine, needs no install, and can do almost anything an HTTP client can: poke an API, download a file, test auth, measure response time. These are the forms you will actually type.

Check a URL and its headers

curl -I https://example.com
curl -s -o /dev/null -w "%{http_code}\n" https://example.com
curl -s https://api.github.com/repos/python/cpython | head -20

The first line fetches only the headers. The second prints just the status code — perfect for scripts and health checks (-s silences the progress bar; add -S to keep errors visible).

POST data and JSON

curl -X POST https://httpbin.org/post -d "name=naresh"

curl -X POST https://httpbin.org/post \
  -H "Content-Type: application/json" \
  -d '{"language":"python","level":"intermediate"}'

-d sends the body, -H sets any header. When the body starts with @ you can send a whole file: -d @payload.json.

Follow redirects, send auth

curl -L https://short.link/x                # follow 301/302 hops
curl -u user:token https://api.example.com   # basic auth
curl -H "Authorization: Bearer TOKEN" https://api.example.com/me

Without -L, curl stops at the first redirect and hands you an empty 301 — the single most common curl "bug".

Download like a pro

curl -O https://example.com/big.iso          # keep remote filename
curl -o local.zip https://example.com/file   # choose the filename
curl -C - -O https://example.com/big.iso     # resume an interrupted download
curl -sSL -o lib.zip https://example.com/lib --retry 3

-C - continues where a stopped download left off, and --retry rides out flaky networks. Both belong in any script that fetches big files.

Uploads, compression, timing

curl -F "file=@photo.png" https://example.com/upload
curl --compressed https://example.com/page          # accept gzip/br
curl -o /dev/null -s -w "total: %{time_total}s\n" https://example.com
curl -v https://example.com 2>&1 | head -30         # full request/response trace

The timing line reports total seconds for DNS, connect, TLS and transfer — useful when you are comparing hosts, as in the website speed checklist.

Quick reference

  • Headers: -I · status only: -w "%{http_code}"
  • POST: -X POST -d ... · JSON: add -H "Content-Type: application/json"
  • Redirects: -L · quiet: -s · verbose: -v
  • Download: -O / -o · resume: -C - · retry: --retry 3
  • Timing: -w "%{time_total}" · gzip: --compressed

One warning: -k / --insecure skips certificate checks. Fine against your own localhost server, never in a script that talks to the real internet.
