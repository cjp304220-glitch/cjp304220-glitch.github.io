30 Linux Commands You'll Actually Use (Cheatsheet)

Every developer ends up in a terminal eventually — a server, a Docker container, a CI runner. These are the commands worth memorising, grouped by job.

Getting around and looking at files

ls -lah               # all files, human sizes, with details
cd /var/log && pwd     # change directory, show where you are
cat file.txt           # print a file
less file.txt          # scroll through a big file (q to quit)
tail -f app.log        # follow a log as it grows
cp -r src dst          # copy recursively
mv old new             # move or rename
rm -rf dir             # delete — check twice before Enter

Finding things

grep -rn "TODO" src/       # search inside files, show line numbers
grep -i "error" app.log    # case-insensitive
find . -name "*.py"        # find files by name
find . -size -10M          # files smaller than 10 MB
history | grep docker      # search your own command history

grep reads stdin, so you can pipe anything into it — that is where the real power is.

Pipes and redirection

command | grep x | head -20   # chain filters
ls -la > out.txt              # overwrite a file with output
ps aux >> out.txt             # append instead
sort data.txt | uniq -d       # duplicate lines, sorted
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head

The last line is the classic "top visitors" one-liner: first column, counted, sorted by frequency. Learn to read pipes left to right and most "magic" shell tricks stop being magic.

Permissions and ownership

chmod +x script.sh      # make executable
chmod 600 id_rsa        # owner read/write only
chmod -R 755 public/    # folder and everything inside it
chown user:group file   # change owner (needs sudo)

Numbers are rwx bits: 7 = read+write+execute, 5 = read+execute, 0 = nothing. 600 on private keys is the one to remember.

Processes and system

ps aux | grep python    # what is running
top                     # live resource view (q to quit)
kill -9 1234            # force a stuck process to die
df -h                   # disk space per mount
du -sh *                # folder sizes, human readable
free -h                 # RAM
uptime                  # load and time since boot

Networking and transfers

ip addr                 # my IP addresses
ping example.com        # is it reachable
ss -tlnp                # which ports are listening
ssh user@host           # remote shell
scp file.txt user@host:/tmp/   # copy a file over SSH
tar -czf backup.tar.gz dir/    # compress a folder
tar -xzf backup.tar.gz         # extract it

For anything HTTP-shaped, there is a dedicated toolkit — the commands in the curl cheatsheet pair perfectly with these.

Shortcuts worth learning

  • Tab — auto-complete paths and commands
  • Ctrl+R — fuzzy-search command history
  • Ctrl+C / Ctrl+D — stop a command / exit a shell
  • !! — rerun the last command (useful with sudo !!)

You do not need all thirty on day one. Get comfortable with navigation, grep, pipes and ps — the rest you will pick up within a month of daily terminal use.
