Vim Basics: The 30 Commands That Make It Usable

The one idea

Vim has modes. In Normal mode keys are commands; press i to Insert (typing); Esc goes back to Normal. Most Vim frustration is being in the wrong mode — look at the bottom-left of the screen.

Move without arrow keys

h j k l     left down up right
w b         word forward / back
0 $         start / end of line
gg G        top / bottom of file
50G         jump to line 50 (any number + G)

Once w/b and gg/G are muscle memory, arrow keys feel like walking backwards.

Edit without leaving Normal mode

i a         insert before / after cursor
o O         new line below / above
x           delete character
dd          delete line
yy p        yank (copy) line, paste below
ciw         change inside word (delete it, start inserting)
dw cw       delete / change to end of word
u / CTRL-r  undo / redo

The c/d/y + motion pattern is the grammar: d$ deletes to end of line, dG deletes to end of file, caw changes a whole word. Learn the grammar, not a hundred separate commands.

Search and replace

/pattern        search forward (n next, N previous)
:%s/old/new/g   replace every "old" with "new" in the file
:%s/old/new/gc  same, but confirm each one

The substitute command is worth memorizing verbatim — it is the one thing people ssh in specifically to use.

Files, quit, force

:w          save
:q          quit
:wq         save and quit
:q!         quit WITHOUT saving
ZZ          save and quit (normal-mode shortcut)

That :q! is the escape hatch for when you opened something you cannot write as your user.

Visual mode

v           select characters
V           select whole lines
CTRL-v      block select (great for editing a column)
then d/y/c  act on the selection

Practice plan

Run vimtutor (ships with Vim, ~25 minutes), then force yourself for two days: no arrow keys, only w/b/dd/yy/p/u. Day three it starts to feel fast. If you live in an editor with a command palette, the keybindings are similar enough that muscle memory carries — as covered in VS Code extensions — and the shell around Vim is the same toolkit from the Linux commands cheatsheet.
