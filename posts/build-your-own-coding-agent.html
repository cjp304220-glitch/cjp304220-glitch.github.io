Build Your Own Coding Agent in 100 Lines of Python

Every "AI coding agent" — the kind that plans, edits files and runs commands — is the same three parts: a language model, a set of tools, and a loop that feeds tool results back until the task is done. Build a tiny one and the magic evaporates.

The loop

user task
  → model (sees task + tool list)
      → model returns text          → done
      → model requests a tool call  → run it locally
                                   → append result, ask model again

The model never touches your machine directly. You run the tool it asked for and paste the output back. That constraint is why the tool design matters more than the prompt.

The agent, ~100 lines

import json, subprocess, os
from openai import OpenAI  # any OpenAI-compatible endpoint works

client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
MODEL = "llama3.1"

def run_command(args):
    '''Run a whitelisted shell command, return its output.'''
    cmd = args["cmd"]
    if not cmd.startswith(("ls ", "cat ", "grep ")):
        return "Error: command not allowed"
    out = subprocess.run(cmd, shell=True, capture_output=True,
                         text=True, timeout=30)
    return (out.stdout + out.stderr)[:4000]

TOOLS = {
    "type": "function",
    "function": {
        "name": "run_command",
        "description": "Run a safe read-only shell command",
        "parameters": {
            "type": "object",
            "properties": {"cmd": {"type": "string"}},
            "required": ["cmd"],
        },
    },
}

def agent(task):
    messages = [{"role": "user", "content": task}]
    while True:
        r = client.chat.completions.create(
            model=MODEL, messages=messages, tools=[TOOLS])
        msg = r.choices[0].message
        messages.append(msg.model_dump())
        if not msg.tool_calls:
            print(msg.content)          # final answer
            return
        for call in msg.tool_calls:
            args = json.loads(call.function.arguments)
            print(">>", args)
            result = run_command(args)
            messages.append({
                "role": "tool",
                "tool_call_id": call.id,
                "content": result,
            })

agent("List the files here and summarise what this project is")

That is the entire skeleton. Swap run_command for read_file, write_file, search — real agents are the same loop with more tools, better prompts and retries.

Safety is the hard part

  • Whitelist tools. Read-only by default; allow writes only in a sandbox folder
  • Never give an unattended shell to the network or your home directory
  • Cap loop iterations and command timeouts — models can thrash
  • Show every tool call to the human; auto-approve is how incidents start

Where to take it next

Point the same loop at bigger models and it behaves like a real assistant — compare the commercial versions in best AI coding agents, and see Ollama for running the model itself offline. The tool-calling prompts are the same discipline as writing better prompts. Building this once is the fastest way to stop trusting agent demos blindly — and the fastest way to trust your own.
